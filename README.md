# AutoCAD

AutoCAD Civil & Architectural Design Project
A collection of engineering and architectural drawings created using AutoCAD, consisting of 4 design files — one civil drawing and three design iterations. These drawings were produced as part of a university design course, demonstrating technical drafting skills and engineering knowledge.
Files included:

Civil_1.dwg — Civil engineering drawing
Design_no_1_Arghya.dwg — First design iteration
Design_no_2.dwg — Second design iteration
Design_no_3_Arghya.dwg — Third design iteration

Tool Used: AutoCAD 2007
